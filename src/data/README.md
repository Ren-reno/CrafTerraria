# Data

`items.json`, `recipes.json` and `ingredient_categories.json` are copies of the files generated by
[terraria-crafting-data-pipeline](https://github.com/Ren-reno/terraria-crafting-data-pipeline).

- **Source commit:** `c6991c92a3a74ee4bde97d98d66b504b27cde547` (extraction of 2026-10-15). The files are
  byte-identical to the previous source commit `81be0bea…`: the data repository was only reorganized in between.
- **License:** CC BY-NC-SA 4.0 (text data from the Official Terraria Wiki). See the data repository's
  [`ATTRIBUTION.md`](https://github.com/Ren-reno/terraria-crafting-data-pipeline/blob/main/ATTRIBUTION.md).
  Item icons are **not** stored here: `imageUrl` points to the wiki.

Do not edit these files by hand: fix the problem in the data repository and copy the new files.

## Refresh from the data repository

From the project root, in PowerShell (replace `<sha>` with the commit you want, and update the line above):

```powershell
$ProgressPreference = 'SilentlyContinue'   # sin barra de progreso: en Windows PowerShell 5.1 hace lenta la descarga
$sha  = "<sha>"
$base = "https://raw.githubusercontent.com/Ren-reno/terraria-crafting-data-pipeline/$sha/data"
foreach ($f in 'items.json','recipes.json','ingredient_categories.json') {
  Invoke-WebRequest "$base/$f" -OutFile "src/data/$f"
}
npm test
```

The data files live in `data/` of the data repository since commit `c6991c9`. For an older commit they sit at the
repository root, so drop the trailing `/data` from `$base`.

`npm test` includes a contract check (`src/services/dataService.test.js`) that fails if the copied files are
inconsistent with each other, for example a recipe pointing to an item that does not exist.
