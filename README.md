# CrafTerraria

App web para consultar recetas de crafteo de Terraria. Proyecto de portafolio.

> **Estado:** en diseño. La definición, los requisitos y la arquitectura están en [`docs/01-definicion-y-requisitos.md`](./docs/01-definicion-y-requisitos.md).

## Datos

Los datos (`items.json` y `recipes.json`) los genera un pipeline propio, que vive en un repositorio aparte: [terraria-crafting-data-pipeline](https://github.com/Ren-reno/terraria-crafting-data-pipeline).

## Atribución

Los datos provienen de la [Official Terraria Wiki](https://terraria.wiki.gg/) y se distribuyen bajo CC BY-NC-SA 4.0, según se detalla en el [`ATTRIBUTION.md`](https://github.com/Ren-reno/terraria-crafting-data-pipeline/blob/main/ATTRIBUTION.md) del repositorio de datos. Terraria es propiedad de Re-Logic; este es un proyecto no oficial, hecho por fans y sin fines comerciales.
